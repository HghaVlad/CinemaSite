# CinemaSite

## Описание
Этот проект — веб-приложение для офлайн-кинотеатра, позволяющее пользователям:
- Просматривать расписание сеансов и доступные фильмы
- Выбирать интересующий фильм и сеанс
- Выбирать места в зале
- Оплачивать билеты онлайн
- Получать билеты в формате PDF

### Актуальность
Данное веб-приложение - удобное цифровое решение для кинотетра. Проект решает несколько ключевых проблем:
- Уменьшает нагрузку на сотрудников кинотеатра
- Автоматизация бронирования - сокращение расходов кинотеатра
- Избавляет от необходимости стоять в очереди в кассе
- Позволяет заранее забронировать лучшие места
- Упрощает процесс оплаты и получения билета

## Запуск проекта

### 1. Клонирование репозитория
Скачайте репозиторий с GitHub:
```sh
git clone https://github.com/HghaVlad/CinemaSite
cd CinemaSite
```

### 2. Создание файла окружения
Создайте `.env` файл на основе `env.example`:
```sh
cp env.example .env
```
Отредактируйте `.env`, введя свои параметры.

### 3. Запуск контейнеров
Используйте команду для сборки и запуска проекта:
```sh
docker-compose up --build
```
После этого сайт будет доступен по адресу `http://localhost`

При необходимости остановить контейнеры используйте:
```sh
docker-compose down
```
