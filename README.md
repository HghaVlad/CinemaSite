### Структура сайта

#### 1. Главная страница (Home)

- **Шапка (Header)** :
    - Логотип кинотеатра.
    - Навигационное меню (Фильмы, Афиша, О нас, Контакты, Вход/Регистрация).
    - Поиск фильмов по названию или категории.
- **Основной контент**:
    - Баннер с анонсом новых фильмов и предстоящих премьер.
    - Раздел "Актуальные фильмы" с карточками фильмов (постеры, названия, рейтинги).
- **Подвал (Footer)** :
    - Контактная информация (адрес, телефон, email).
    - Социальные сети.
    - Политика конфиденциальности и пользовательское соглашение.

#### 2. Страница фильма (Movie Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    - Постер фильма.
    - Название фильма, жанр, продолжительность, возрастное ограничение.
    - Рейтинг фильма (например, IMDb, Kinopoisk).
    - Краткое описание сюжета.
    - ~~Трейлер фильма (встроенный видео-плеер).~~
    - Расписание показов с возможностью выбора даты и времени.
    - Кнопка "Купить билет" для перехода к выбору мест.
- **Подвал (Footer)** :
    - Контактная информация и социальные сети.

#### 3. Страница афиши (Schedule Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    - Фильтры для выбора фильма, даты и времени.
    - Таблица или список с расписанием всех сеансов на выбранный день.
    - Для каждого сеанса: название фильма, время начала, зал, наличие свободных мест.
    - Кнопка "Выбрать места" для перехода к покупке билетов.
- **Подвал (Footer)** :
    - Контактная информация и социальные сети.

#### 4. Страница выбора мест (Seat Selection Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    
    - Схема зала с указанием занятых и свободных мест.
    - Информация о выбранном фильме и времени сеанса.
    - Возможность выбрать несколько мест.
    - Отображение стоимости выбранных мест.
    - Кнопка "Перейти к оплате".
- **Подвал (Footer)** :
    - Контактная информация и социальные сети.

#### 5. Страница оплаты (Payment Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    - Итоговая информация о заказе (название фильма, время сеанса, выбранные места, общая стоимость).
    - Форма для ввода данных карты (номер карты, срок действия, CVV).
    - Уведомление о безопасности платежа.
    - Кнопка "Оплатить".
- **Подвал (Footer)** :
    - Контактная информация и социальные сети.

#### 6. Страница профиля пользователя (User Profile Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    - Информация о пользователе (имя, email, контактный телефон).
    - История покупок (список ранее купленных билетов с деталями).
    - Возможность редактирования профиля (изменение пароля, обновление контактной информации).
    - Кнопка выхода из аккаунта.
- **Подвал (Footer)** :
    
    - Контактная информация и социальные сети.

#### 7. Страница регистрации/входа (Sign Up/Login Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    - Форма регистрации (имя, email, пароль, повторный пароль).
    - Форма входа (email, пароль).
    - Возможность восстановления пароля.
    - Кнопка "Войти через социальные сети" (Google, Facebook и т.д.).
- **Подвал (Footer)** :
    - Контактная информация и социальные сети.

#### 8. Страница контактов (Contacts Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    
    - Контактная информация (адрес, телефон, email).
    - Карта с расположением кинотеатра.
    - Форма обратной связи (имя, email, сообщение).
- **Подвал (Footer)** :
    
    - Контактная информация и социальные сети.

#### 9. Страница о нас (About Us Page)

- **Шапка (Header)** :
    - Логотип и навигационное меню.
- **Основной контент**:
    
    - История кинотеатра.
    - Описание услуг и преимуществ.
    - Команда кинотеатра (фото и краткая информация о сотрудниках).
- **Подвал (Footer)** :
    
    - Контактная информация и социальные сети.
